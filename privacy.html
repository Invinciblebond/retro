AnswerSolution
Privacy Policy

We have no servers,
so we receive nothing.

AnswerSolution is a browser extension that explains things on the page you are reading. It talks directly from your browser to Google, using an API key you supply. Nothing is routed through us, because there is no “us” in the request path.

Effective 5 September 2026

The short version

The developer of AnswerSolution never receives, stores, or has access to your content, your API key, or your browsing. There is no account, no backend, no analytics, and no tracking of any kind.

What the extension sends, and where

A request is only ever made when you start one — by clicking a right-click menu item, pressing a keyboard shortcut you assigned, or using a button in the extension’s popup. The extension never captures or transmits anything on its own, in the background, or on a timer.

When you start a scan, one request goes directly from your browser to Google’s Gemini API at generativelanguage.googleapis.com, authenticated with the API key you saved. It contains:

  • the text you highlighted, or a screenshot of the visible tab, or a screenshot of the region you dragged out;
  • the page title and URL, as context for the question;
  • the system prompt and any extra instruction you set in Settings.

Google’s handling of that request is governed by Google’s Privacy Policy and the terms attached to your own API key. We are not a party to it.

What is stored, and where it lives

Everything the extension saves is stored by your browser on your own machine. None of it is transmitted to the developer.

API keys
chrome.storage.local — deliberately never synced, so keys stay on the one device.
Usage counters
Per-key daily request counts and rate-limit cooldowns. Local only.
Request log
The last 100 requests: timestamp, kind, HTTP status, duration. No content, no URLs. Local only, and clearable in Settings.
Preferences
Model, effort, system prompt, discreet mode. chrome.storage.sync, so they follow your Chrome profile — this is Chrome’s own sync, not ours.

Uninstalling the extension removes all of it.

Permissions, and why each one exists

activeTab
Reads the current tab only at the moment you start a scan, to take the screenshot or read your selection. It grants no access to other tabs and none in the background.
scripting
Draws the answer panel and the drag-to-select overlay on the page you are scanning.
contextMenus
Adds the right-click entries used to start a scan.
storage
Saves the settings and keys described above.
generativelanguage.googleapis.com
The Gemini API — the only host the extension ever contacts.

Data we do not touch

The extension does not, and will not:

  • collect or log your browsing history or the pages you visit;
  • record keystrokes, clicks, mouse movement, or scrolling;
  • read pages you have not explicitly asked it to scan;
  • sell or transfer data to third parties, advertisers, or data brokers;
  • use data for personalised advertising;
  • use data to determine credit-worthiness or for lending purposes.

Use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your control

Because nothing leaves your machine except the request you initiate, there is no account to delete and no data of yours for us to hand over or erase. You can remove your keys and clear the local request log at any time from Settings, or uninstall the extension to remove everything at once.

Your API key belongs to you. You can revoke it in Google AI Studio at any time, which immediately stops the extension from being able to make requests.

Children

AnswerSolution is a study tool intended for general audiences and is not directed at children under 13. It collects no personal information from anyone, including children.

Changes

If this policy changes in a way that affects what the extension sends or stores, the effective date above will change and the update will be described in the extension’s release notes. Material changes will not be applied retroactively to data already on your device — there is none held anywhere else.

Contact

Questions about this policy, or about anything the extension does, are welcome in the support server.
